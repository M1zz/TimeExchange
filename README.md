# 시간 환전소 (TimeExchange)

시간과 돈 사이의 **환율**을 기록하는 iOS 앱.

돈을 쓰고 시간을 사는 거래(택시, 가사 대행)가 실제로 시간을 늘렸는지, 아니면 다른 날에서 빌려온 것뿐인지를 계산한다.

## 핵심 개념

거래는 두 방향뿐이다.

| 방향 | 의미 |
|---|---|
| **입금** | 시간 → 돈. 일해서 번 돈을 저축한다. |
| **출금** | 돈 → 시간. 돈을 써서 시간을 되산다. |

출금할 때 두 개의 시급을 비교한다.

```
번 ÷ 산 > 1   내 시급보다 싸게 샀다 → 시간이 실제로 늘어남
번 ÷ 산 = 1   시간이 이동만 함
번 ÷ 산 < 1   비싸게 샀다 → 다른 날에서 빌려옴
```

그리고 **순증** = 돌려받은 시간 − 그 돈을 벌려고 쓴 시간.

## 환율은 직접 입력하지 않는다

시급을 손으로 찍으면 사람은 자기 시간을 후하게 잡고, 그러면 모든 출금이 이득으로 보이는 자기합리화 도구가 된다. 그래서 월급에서 도출한다.

```
노동 환율 = 월 실수령액(세후) ÷ (월 근무시간 + 월 통근시간)
```

분모에 **통근을 포함**하는 것이 핵심이다. 급여에 잡히지 않지만 회사 때문에 쓰는 시간이므로 판 시간이 맞다. 통근을 빼면 시급이 약 19% 부풀려진다.

자산은 성격이 다른 환율을 하나 더 만든다.

```
자산 환율 = 자산 × 연 기대수익률 ÷ 8,760h
```

근무시간이 아니라 달력 시간(1년 전체)으로 나누는 이유는 자산이 자는 동안에도 일하기 때문이다. 이 값은 참고 지표일 뿐이며, **출금 순증 계산에는 노동 환율만 사용한다.** 성격이 다른 두 숫자를 합치면 의미가 섞이기 때문이다.

## 화면

- **오늘** — 현재 환율, 잔고, 오늘 하루의 길이와 밀도
- **거래내역** — 날짜별 거래와 일별 순증
- **환율** — 월급·근무시간·자산 입력, 도출된 시급 확인

## 기술

- SwiftUI + SwiftData
- iOS 17.0+
- Swift 5 (Swift 6 언어 모드에서도 경고 없이 빌드됨)

거래 시점의 환율은 `Exchange.myRateAtTime`에 스냅샷으로 저장된다. 나중에 시급이 바뀌어도 과거 거래의 판단은 그대로 남는다.

## 빌드

```bash
xcodebuild -project TimeExchange.xcodeproj \
           -scheme TimeExchange \
           -destination 'platform=iOS Simulator,name=iPhone 17' \
           build
```

클론 후 `DEVELOPMENT_TEAM`을 본인 것으로 바꿔야 실기기 빌드가 된다.
